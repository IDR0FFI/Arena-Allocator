# Arena Allocator

A simplistic implementation of arena allocator in C for personal usage.
Feel free to use and modify the program.

Inspired from the Ryan Fleury's blog: https://www.dgtlgrove.com/p/untangling-lifetimes-the-arena-allocator
So most of the initial implementation is based of it.
I am willing to go and try to add other modification which may sway away from simple API interface; adding deep level of abstraction but let's see.

## Usage
Add the `arena` folder directly into your program directory with the necessary build rules.

There is a simple example file attached will be helpful as the base Arena implementation grows.
